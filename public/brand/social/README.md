## Format

WebP, 1080×1350 (Instagram's 4:5 portrait — the largest slot in the feed and
what these were designed at). If you only have PNG or JPG, drop them in with
the same base name and tell me; the brand pipeline in `scripts/` converts and
resizes them.

Keep the originals somewhere outside the repo. These are the display copies.
