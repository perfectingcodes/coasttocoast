---
name: CRM access model
description: The user's preference for simple password-only access to the Coast to Coast Air CRM.
---

The CRM admin uses one shared password stored as a Replit Secret, not per-user email accounts.

**Why:** The user preferred a simple password gate over choosing staff email addresses.

**How to apply:** Keep CRM sign-in simple unless the user asks for individual accounts, roles, or audit attribution.
